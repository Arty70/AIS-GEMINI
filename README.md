# Волшебный Гардероб - Magical Wardrobe

Современное Android приложение для создания и изменения образов с помощью искусственного интеллекта Gemini AI. Приложение позволяет пользователям загружать свои фотографии и генерировать новые образы в различных стилях с высоким качеством 4K.

## ✨ Основные возможности

- **ИИ-генерация образов**: Использование Gemini AI для создания новых образов на основе загруженных фотографий
- **4K качество**: Генерация изображений в высоком разрешении
- **Множество стилей**: Деловой, вечерний, повседневный, спортивный, романтичный, креативный
- **Управление гардеробом**: Сохранение и организация созданных образов
- **Современный дизайн**: Красивый UI с Material Design 3 и градиентами
- **Русская локализация**: Полная поддержка русского языка

## 🏗️ Архитектура

Приложение построено с использованием современных Android технологий:

- **Jetpack Compose** - современный UI toolkit
- **Material Design 3** - последняя версия дизайн-системы Google
- **MVVM архитектура** - с использованием ViewModel и StateFlow
- **Hilt** - для внедрения зависимостей
- **Navigation Compose** - для навигации между экранами
- **Coroutines** - для асинхронных операций

## 🔧 Настройка

1. **Получите API ключ Gemini AI**:
   - Зарегистрируйтесь в Google AI Studio
   - Получите API ключ
   - Замените `YOUR_GEMINI_API_KEY` в `GeminiRepository.kt`

2. **Скачайте шрифты Inter**:
   - Скачайте шрифты Inter с Google Fonts
   - Поместите файлы в `app/src/main/res/font/`

3. **Соберите проект**:
   ```bash
   ./gradlew assembleDebug
   ```
