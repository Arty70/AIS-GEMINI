## 🎯 Основные функции

### **Настройка API ключа**
1. Перейдите в **Профиль** → **Настройки**
2. Нажмите **"Настроить API ключ"**
3. Вставьте ключ из Google AI Studio
4. Приложение автоматически проверит ключ

### **Валидация ключа**
- ✅ Проверка формата ключа
