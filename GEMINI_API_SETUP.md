# 🔑 Настройка Gemini AI API для Волшебного Гардероба

Это руководство поможет вам настроить API ключ Gemini AI для работы приложения.

## 📋 Шаги настройки

### 1. Получение API ключа

1. **Перейдите на Google AI Studio**
   - Откройте https://aistudio.google.com/
   - Войдите в свой аккаунт Google

2. **Создайте API ключ**
   - Нажмите "Get API key" в левом меню
   - Выберите "Create API key"
   - Выберите проект или создайте новый
   - Скопируйте созданный API ключ

### 2. Настройка в приложении

#### Способ 1: Через настройки приложения
1. Запустите приложение
2. Перейдите в **Профиль** → **Настройки**
3. Нажмите **"Настроить API ключ"**
4. Вставьте ваш API ключ
5. Нажмите **"Сохранить"**

#### Способ 2: Программно (для разработчиков)
Замените `YOUR_GEMINI_API_KEY` в файле `ApiConfig.kt`:

```kotlin
private const val DEFAULT_API_KEY = "ваш_реальный_api_ключ_здесь"
```

### 3. Проверка настройки

После настройки API ключа:
- ✅ В настройках появится статус "API ключ настроен"
- ✅ Приложение сможет генерировать образы с помощью ИИ
- ✅ Все функции 4K генерации будут доступны

## 🔧 Технические детали

### Зависимости
Приложение использует следующие библиотеки для работы с Gemini AI:

```gradle
implementation 'com.google.ai.client.generativeai:generativeai:0.2.2'
implementation 'com.google.generativeai:generativeai:0.2.2'
```

### Конфигурация
API ключ сохраняется в `SharedPreferences` с ключом `gemini_api_key`.

### Валидация
Приложение автоматически проверяет:
- Формат API ключа
- Подключение к сервису Gemini AI
- Корректность ответов

## 🚨 Устранение проблем

### Ошибка "API ключ недействителен"
- Проверьте правильность скопированного ключа
- Убедитесь, что ключ активен в Google AI Studio
- Проверьте интернет-соединение

### Ошибка "Неверный формат API ключа"
- API ключ должен содержать только буквы, цифры, дефисы и подчеркивания
- Длина ключа должна быть больше 20 символов
- Убедитесь, что скопировали ключ полностью

### Ошибка подключения
- Проверьте интернет-соединение
- Убедитесь, что сервис Gemini AI доступен
- Попробуйте перезапустить приложение

## 📱 Использование

После успешной настройки API ключа:

1. **Создание образов**
   - Перейдите в **Камера**
   - Выберите фото или сделайте снимок
   - Выберите стиль (деловой, вечерний, и т.д.)
   - Нажмите **"Создать образ с ИИ"**

2. **4K генерация**
   - Все созданные образы будут в высоком качестве
   - Возможность улучшения качества до 4K
   - Сохранение в галерею устройства

3. **Управление гардеробом**
   - Просмотр всех созданных образов
   - Фильтрация по стилям
   - Добавление в избранное

## 🔒 Безопасность

- API ключ хранится локально на устройстве
- Ключ не передается третьим лицам
- Все запросы к Gemini AI идут напрямую с вашего устройства

## 💡 Советы

- Сохраните API ключ в надежном месте
- Не делитесь ключом с другими
- Регулярно проверяйте использование в Google AI Studio
- При подозрении на компрометацию - создайте новый ключ
